# 🐾 9하개 | 유기견 보호·입양 웹사이트

**9하개**는 유기견에 대한 사회적 관심을 높이고, 책임 있는 입양과 후원 참여를 돕기 위해 제작한 팀 웹 프로젝트입니다. 보호 동물 정보 확인부터 입양 신청, 입양 후기, 후원 안내까지 한곳에서 살펴볼 수 있도록 구성했습니다.

실제 유기동물 보호센터 웹사이트의 정보 구조를 참고하여 **7개의 HTML 페이지와 5개의 CSS 파일**로 구현했습니다. 이 프로젝트에서 저는 팀장으로 참여하여 **전체 페이지의 CSS 작성과 스타일링을 담당**하고, 메인 페이지 HTML 제작에도 일부 참여했습니다.

## 기획 의도

유기견 입양을 고민하는 이용자가 보호 동물의 정보를 쉽게 탐색하고, 자신의 양육 환경과 책임을 충분히 고려한 뒤 입양을 결정할 수 있도록 기획했습니다. 입양 외에도 후기와 후원 콘텐츠를 제공하여 유기견 보호 활동에 관심을 갖고 참여할 수 있는 경로를 마련했습니다.

HTML과 CSS를 활용해 실제 보호센터 웹사이트의 주요 화면을 구현하면서, 정보 탐색과 신청서 작성을 고려한 **사용자 중심의 화면 설계와 디자인**을 목표로 했습니다.

## 나의 기여

### 전체 페이지 CSS 작성 및 스타일 구조 설계

프로젝트에 사용된 **CSS 파일 5개를 모두 담당**했습니다. 공통 UI와 페이지별 스타일을 분리하고, 각 HTML에 필요한 CSS를 연결하는 방식으로 구성했습니다.

- **공통 스타일 분리:** 헤더, 상단 메뉴, 좌측 내비게이션, 푸터, 버튼, 입력창 등 여러 페이지에서 사용하는 요소의 디자인 통일
- **페이지별 적용 범위 구분:** `body` 클래스 선택자를 활용하여 페이지별 스타일 충돌과 코드 중복을 줄이도록 구성
- **공통 디자인 값 관리:** `:root`에 CSS 사용자 정의 속성을 선언하여 색상과 둥근 모서리 등 반복되는 값 재사용
- **Flexbox 기반 배치:** 메뉴, 본문, 동물 카드, 상세정보 및 신청서 항목의 정렬과 간격 조정

### 친근하고 일관된 디자인 구현

유기견 보호·입양이라는 주제에 맞춰 **민트색과 베이지색**을 중심으로 따뜻하고 편안한 분위기를 표현했습니다.

- 공통 헤더와 푸터, 좌측 메뉴·중앙 콘텐츠·우측 마스코트 영역으로 이어지는 일관된 화면 구성
- 카드, 버튼, 이미지에 둥근 모서리와 그림자를 적용한 부드러운 디자인
- 보호 동물의 사진을 중심으로 정보를 비교할 수 있는 카드형 레이아웃
- 제목과 본문, 안내 문구, 입력 항목의 크기와 여백을 조정한 가독성 개선

### 인터랙션 및 입력 폼 스타일링

마우스 움직임에 따른 시각적 변화와 명확한 입력 항목 구분을 통해 이용자가 화면을 이해하고 조작하기 쉽도록 스타일링했습니다.

- `:hover`, `transform`, `transition`을 활용한 카드와 버튼의 색상·위치·그림자 변화
- 우측 강아지 마스코트에 마우스를 올렸을 때 위아래로 움직이는 효과
- 입양 후기 카드에 마우스를 올리면 내용을 확인할 수 있는 오버레이
- 신청서의 질문 그룹, 입력창, 필수 안내 및 동의 항목을 구분하는 스타일
- 긴 신청서도 순서대로 읽을 수 있도록 항목별 간격과 강조 표현 조정

## 주요 구현 특징

### 보호 동물을 쉽게 탐색하는 화면

사진 중심의 카드 목록과 지역별 이동 메뉴를 구성했습니다. 동물 상세 페이지에는 사진과 주요 정보를 나란히 배치하여 외형과 보호 정보를 함께 확인할 수 있도록 했습니다.

### 책임 있는 입양을 고려한 신청서

입양 희망자의 기본정보 외에도 주거환경, 가족과 집주인의 동의, 양육 경험, 경제적 여건, 입양 동기와 향후 양육 계획을 확인하는 항목을 구성했습니다.

관련 질문은 `fieldset`과 `legend`로 묶고, `label`과 `placeholder`로 입력 내용을 안내했습니다. 필수 항목에는 `required` 속성을 적용하여 브라우저의 기본 입력 검사를 활용했습니다.

### 입양 외의 참여 경로 제공

입양 후기와 별도의 기부·후원 페이지를 마련했습니다. 후기에서는 입양 이후의 이야기를 살펴보고, 후원 페이지에서는 후원금 사용 목적과 집행 현황, 정기·일시·물품 후원 신청 화면을 확인할 수 있습니다.

### 시각·청각 요소를 활용한 주제 표현

강아지 마스코트와 마우스 반응 효과로 친근한 분위기를 더하고, 메인 페이지에는 강아지 짖는 소리의 MP3 오디오를 연결했습니다. 오디오는 자동 재생을 설정했으며, 실제 재생 여부는 브라우저 정책에 따라 달라질 수 있습니다.

## 실행 방법

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/skgmny/Save-Dog-Website.git
   ```

2. `Save-Dog-Website` 폴더의 **`9_9하개_main.html`** 파일을 웹 브라우저로 엽니다.
3. 상단 메뉴와 좌측 내비게이션을 통해 각 페이지와 콘텐츠 영역으로 이동합니다.

VS Code에서는 Live Server 확장을 사용하여 실행할 수도 있습니다.

입양 신청, 후기 작성, 후원 신청 폼과 브라우저의 기본 입력 검사를 구현했으며, 서버 연동을 통한 데이터 저장·실제 신청 처리·후기 등록·결제 기능은 포함하지 않습니다.
