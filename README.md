# 🐾 9하개 | 유기견 보호·입양 웹사이트

유기견 보호와 책임 있는 입양을 주제로 제작한 팀 웹 프로젝트입니다. 보호 중인 동물 소개부터 입양 신청, 입양 후기, 후원 안내까지 하나의 웹사이트에서 살펴볼 수 있도록 구성했습니다.

## 프로젝트 소개

- **프로젝트명:** 9하개 (Save-Dog-Website)
- **개발 형태:** HTML·CSS 기반의 정적 웹사이트
- **참여자:** 김사랑, 김윤하, 조민체, 최석인
- **나의 담당 역할:** 전체 페이지의 CSS 작성 및 스타일링

## 나의 기여

이 프로젝트에서 **모든 CSS를 담당**했습니다. 공통 스타일과 페이지별 스타일을 나누어 작성하고, 사이트 전반에 일관된 색상과 레이아웃을 적용했습니다.

- **공통 UI 스타일링:** 헤더, 내비게이션, 푸터, 사이드 메뉴, 버튼, 입력 폼의 스타일 구현
- **색상 및 스타일 관리:** CSS 사용자 정의 속성으로 민트·베이지 계열 색상과 그림자 등을 공통 관리
- **페이지별 레이아웃:** Flexbox를 활용한 동물 카드 목록, 상세 정보, 소개 콘텐츠, 신청 폼 배치
- **인터랙션 표현:** 카드와 버튼의 호버 효과, 그림자, 전환 효과 및 후기 카드의 오버레이 구현
- **콘텐츠 가독성:** 제목, 본문, 안내 문구, 입력 항목의 간격과 시각적 구분 조정

| 파일 | 담당 영역 |
| --- | --- |
| `9_9하개_common2.css` | 전체 페이지 공통 색상, 레이아웃, 헤더·푸터, 메뉴, 버튼 및 폼 |

| 페이지 | 주요 내용 | 파일 |
| --- | --- | --- |
| 메인 | 공지사항, 보호 동물, 베스트 입양 후기, 기부 안내 | `9_9하개_main.html` |
| 회사 소개 | 보호센터 소개, 시설, 핵심 가치, 연혁, 운영 현황 및 위치 | `9_9하개_introduce.html` |
| 보호 중인 동물 | 지역별 보호 동물 목록 및 입양 전 안내 | `9_9하개_adopt-list.html` |

## 사용 기술

- **HTML5:** 페이지 구조, 내비게이션, 표, 입력 폼 구성
- **CSS3:** Flexbox, CSS 사용자 정의 속성, 가상 클래스, 전환 효과를 활용한 스타일링
- **이미지·미디어:** PNG, JPG, SVG 이미지 및 MP3 오디오

별도의 JavaScript 프레임워크나 빌드 도구 없이 실행할 수 있습니다.

## 실행 방법

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/skgmny/Save-Dog-Website.git
   ```

2. `Save-Dog-Website` 폴더 안의 **`9_9하개_main.html`** 파일을 웹 브라우저로 엽니다.
3. 상단 메뉴를 통해 각 페이지로 이동합니다.

VS Code를 사용하는 경우 Live Server 확장으로 메인 HTML 파일을 실행할 수도 있습니다.

## 구현 범위

이 저장소는 화면 구성과 스타일링을 중심으로 한 정적 웹 프로젝트입니다. 입양 신청, 후기 작성, 후원 신청 폼은 서버와 연결되어 있지 않으며, 입력 내용 저장이나 실제 결제 기능은 구현되어 있지 않습니다.
